# packages

Home of the real Backstage app, following Backstage's standard monorepo
convention:

- `app-backstage/` — Portal UI (React/TS). Chatbot/Agent UI plugins will be integrated here.
- `backend/` — Core Backstage backend (Node.js), serving Catalog, Scaffolder, TechDocs...

Run in dev mode: `yarn start` at the repo root (script defined in the root `package.json`).
